# Amazon S3 — Simple Storage Service

Source: https://docs.aws.amazon.com/AmazonS3/latest/userguide/Welcome.html

## Overview

Amazon Simple Storage Service (Amazon S3) is an object storage service that provides scalability, data availability, security, and performance.

S3 stores data as objects inside buckets. Each object consists of data, a key, and metadata.

## Buckets

A bucket is a container for objects stored in Amazon S3.

Key characteristics:

- Bucket names must be globally unique within an AWS partition.
- Buckets are created in a specific AWS Region.
- Objects are stored inside buckets.
- Access can be controlled using IAM policies, bucket policies, and other access mechanisms.

## Objects

An S3 object is a file and its associated metadata.

Each object contains:

- Key: the unique identifier of the object within a bucket.
- Data: the actual content.
- Metadata: information describing the object.

## Storage Classes

Amazon S3 offers different storage classes for different access patterns and cost requirements.

Examples include:

- S3 Standard: frequently accessed data.
- S3 Intelligent-Tiering: data with changing or unpredictable access patterns.
- S3 Standard-IA: infrequently accessed data.
- S3 Glacier Flexible Retrieval: long-term archival storage.
- S3 Glacier Deep Archive: long-term archival with very infrequent access.

## Lifecycle Management

S3 Lifecycle rules allow automatic transitions between storage classes and automatic object expiration.

Common use cases:

- Moving older objects to lower-cost storage classes.
- Automatically deleting expired objects.
- Managing storage costs over time.

## Security

Amazon S3 provides several mechanisms to control access and protect data:

- IAM policies.
- Bucket policies.
- Access Points.
- Block Public Access.
- Server-side encryption.

## Common Use Cases

- Backup and recovery.
- Data lakes.
- Application file storage.
- Static website hosting.
- Log and media storage.
